## Notes

Wheeled bimanual mobile manipulator (not a humanoid; category should be Mobile platform/wheeled manipulator). Maker docs give 576 Wh battery (2x 24 V Li-ion in parallel), four 720p RGB cameras (two wrist, overhead, front), Raspberry Pi 5 onboard, Python/TypeScript nori-sdk; robot-side stack uses ROS 2 packages (ros2 run nori_cameras). Maker site now sells only the successor Nori A3 ($1,688) and the SDK docs refer to a 'frozen L2 fleet', so L2 is superseded (status Discontinued is inferred). Launch price $1,288 (L2 Grande $1,322) reported by press/aggregators, not seen on a maker page — left out. Height 100 cm also aggregator-only.
